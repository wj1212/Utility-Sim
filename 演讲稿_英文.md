# Five-minute talk, English script

中文版在 `演讲稿_中文.md`，意思以那份为准，这份是**照着念的**。

**标准是"简单"，不是"漂亮"。** 短句、常用词、不要从句套从句。

**人称分工**：做的事用 **we**（we built, we measured），判断和自省用 **I**（I cannot tell, my own design）。
样例里 Dikshant 全程用 we，所以 we 是安全的；但自省那几句用 I，责任才落得下来。

**每页三部分**：页面上放什么 · 照着念的话 · 讲的时候注意什么。

---

# 1　Title　`14 秒`

**页面上**
```
Response Curves and Action Inertia
in Utility-Based NPC Agents

Wenjie Jiang
Advisor: Navid Amini, PhD
October 2026
```

**念**

> Good afternoon. My name is Wenjie Jiang, and my advisor is Professor Navid Amini.
>
> Our project is about response curves and action inertia in utility-based NPC agents.

> 念完**直接翻页，不解释**。解释交给第 2 页。

---

# 2　Deciding on Their Own　`32 秒`

**页面上**
- 那张**正经吃饭**的 Sims 截图，占大部分版面
- 图正下方极小字：`The Sims 4, Electronic Arts`
- 右下角小字灰色：`(Mark, 2009)`

**念**

> In this kind of game, the characters act on their own. They get hungry, and they go and eat. Nobody tells them to.
>
> They have more than one need at the same time, so they always have to choose. Getting that choice right is harder than it looks.
>
> So how do you build that? One approach is scoring. A character has several things it could do, and it gives each one a score. It does the one with the highest score.
>
> Response curves and action inertia are two parts of how that score is worked out. Those two are what we measure.

> **第二段是钩子**，不要展开。"harder than it looks" 之后直接走，第 6 页才揭晓。
>
> 被问「Why cite Mark here?」：
> `Because scoring is an existing approach, and that is where it is set out. I found the book and the GDC talks and I know what they cover. Reading them properly is on my list before the written thesis.`

---

# 3　The Simulation　`22 秒`

**页面上**　只有标题 + **Unity 截图**（俯视，看得见两个角色、冰箱、床）

**念**

> So we built a very small version of that. One room. The character has two needs, hunger and energy, and both go down over time. There is a fridge, and there is a bed.
>
> We kept it small on purpose. If there are too many variables, and something happens, we cannot tell what caused it.

> 开头 `a very small version of that` 把这页和上一页接上了。

---

# 4　Two Agents　`22 秒`

**页面上**　两栏，用你场景里那两个圆圈的实际颜色当标记
```
  ● Threshold              ● Utility

  Act below a line         Score every option
  Fixed order              Pick the highest
```

**念**

> We built two characters. They see the world in exactly the same way. The only difference is the part that makes the decision.
>
> One uses threshold rules. When a need drops below a line, it goes and deals with it.
>
> The other one uses scoring. Every action gets a number, and the highest number wins.

> **不要说阈值规则落后或者简单。** 它回答的是另一个问题，而且后面数据会显示它在平稳环境里表现一样好。

---

# 5　Response Curves　`22 秒`

**页面上**　只有标题 + `fig_09_curves.png`
右下角小字灰色：`(Mark, 2009)`

**念**

> So where does that number come from? From how empty the need is. That conversion is called a response curve. It is the first word in our title.
>
> It can be a straight line. Or it can be bent. We used a bent one, because urgency is not linear. Going from a little hungry to very hungry is a big change. Going from very full to a little full is almost nothing.

---

# 6　Oscillation　`30 秒`　**不能删**

**页面上**　只有标题 + `fig_13_problem.png`

**念**

> With scoring in place, I thought the problem was solved. It was not.
>
> The character is sleeping. The score for eating slowly goes up. The score for sleeping slowly goes down. At some point eating wins, so it gets up and walks to the fridge. Halfway there, sleeping comes back up, so it turns around and walks back to the bed.
>
> This is what that looks like in our data. In this run, eighty one percent of its decisions threw away something it had already started.

> **这就是第 2 页说的 "harder than it looks"。** 没有这一页，下一页的动作惯性就是凭空出现的。
>
> `It was not.` 之后停一下。

---

# 7　Action Inertia　`34 秒`

**页面上**　公式放大居中，下面两行小字
```
score(a) = f(need) + β · 1[a is the current action]
```
```
f   the response curve
β   the commitment bonus
```

**念**

> So we needed a second thing. Give a small bonus to whatever the character is already doing. Then another option has to be clearly better before it can push that one out. This is the second word in our title.
>
> Put together, the score for one action is this line. f is the curve. Beta is the inertia.
>
> These two control the same thing: how easily the character changes its mind. The curve decides how far apart the scores can get. The inertia decides how far apart they have to be.
>
> So we turned each one off and on. Four combinations, eight runs each.

> 教授说过八月那份 deck 没有公式。**这一页就是回应。**
>
> 念到 `f` 和 `β` 的时候用手指一下屏幕。
>
> 被问「Is action inertia a standard term?」：
> `The idea of committing to what you are already doing goes back to work on intentions, Bratman and others. The name and the exact form in my implementation are my own choice.`

---

# 8　Metrics　`28 秒`　**不能删**

**页面上**　三行，不要写定义
```
Interruptions
Collapse
Measurement noise
```

**念**

> Before the results, I should say what we are measuring against.
>
> For stability we count interruptions, which means how often it drops what it is doing. For failure we count collapse. If more than eighty percent of the decisions in a run are dropping something, we count that run separately, because that is a different kind of failure.
>
> And one more thing. There are two characters in the room, and they block each other. We measured how big that interference is. It is four point nine percentage points. Anything smaller than that, we do not call a finding.

> 被问「Why eighty percent?」：
> `That line is mine. But the conclusion does not depend on it. At seventy or ninety percent, the runs with inertia still never cross it.`

---

# 9　Averages　`18 秒`

**页面上**　BIG_NUMBER 版式
```
4.3 pp
```
下面一行小字：`the measurement noise is 4.9`

**念**

> First, with nothing removed. The four combinations sit on top of each other. The difference is smaller than the noise we just measured.
>
> So on the average, nothing shows up.

> **慢一点念。** 听众要先相信"什么都没有"，下一页才有力量。

---

# 10　Run by Run　`40 秒`　**全场重点**

**页面上**　只有标题 + `fig_03_collapse_dots.png`

**念**

> Then we stopped looking at the average, and drew every single run.
>
> Each dot is one run. Red means that run collapsed.
>
> Look at the left side. That is the one where nothing was removed. The one where nothing showed up. Without inertia, five runs out of sixteen collapsed. With inertia, none.
>
> The average was not lying. The typical run really is the same.
>
> But the problem was never in the typical run.

> **全场最慢的一页。**
> `With inertia, none.` 之后停住。最后两句之间再停一次。最后一句念完不要马上翻页。

---

# 11　*(不要标题)*　`22 秒`

**页面上**　MAIN_POINT 版式，只有一句话居中
```
It does not make the normal run better.
It takes away the disaster.
```

**念**

> So I changed how I describe it. At least in our setup, action inertia is more like a mechanism that removes failures, than one that improves performance.
>
> It does not make the normal run better. It takes away the disaster.
>
> If we take the fridge away for a while and then give it back, the same effect gets about ten times bigger, in the same direction.

> **这页故意没有标题。** 标题写 "Reliability" 等于把结论先说了，
> 你开口就成了复述幻灯片。让那句话自己站着。

---

# 12　Tuning　`20 秒`

**页面上**　只有标题 + `fig_01_sweep.png`

**念**

> So is more always better? No.
>
> We tried five values, and the result is a U shape. Too small, and it cannot settle. Too large, and it gets worse again.
>
> In our setup, around zero point two to zero point three works best.

> **不要解释"为什么太大会更糟"。** 原来那个解释已经撤回了。
>
> 被问到才答：`It switches later, and it waits until the other need is lower. But why there are more interruptions, I do not have a verified explanation yet.`

---

# 13　Sensitivity　`32 秒`

**页面上**　只有标题 + `fig_09_curves.png`（第 5 页那张再用一次）

**念**

> Now back to the first word in our title. We made the curve non-linear, and compared it against a straight line. In both cases the difference was small. I cannot tell it apart from the noise.
>
> But then I checked something. At the point where most decisions happen, the bent line and the straight line are only zero point zero one apart.
>
> To keep the comparison clean, we lined the two conditions up at the same point. And that point is exactly where most of the decisions happen. So this result may not be about the curve. It may be about how sensitive our experiment is.

> **不要说 "no effect"，要说 "cannot tell it apart from the noise"。**

---

# 14　Results　`20 秒`

**页面上**　两行
```
Inertia removes the failures, not the average
Curve shape: cannot be resolved here
```

**念**

> Two results.
>
> Action inertia is more like a reliability mechanism. It does not improve the normal run. It removes the disaster.
>
> And the shape of the curve. In this setup, I cannot tell the difference.

---

# 15　Next Steps　`36 秒`

**页面上**　三行
```
Sweep curvature, not just on and off
One agent per run
Add a third need
```

**念**

> But looking back, I did not treat the two mechanisms equally. For inertia I tried five values. For the curve I only had on and off. One is a sweep, the other is a yes or no question. So part of the reason the curve has no result is my own design.
>
> So, three things next. First, sweep the curvature the same way, so the curve gets the same treatment. Second, run one character at a time, to remove that four point nine of interference. Third, add a third need.

> **全场第二重要的一段。** 它把 null 结果从"我没做出来"变成
> "我没给它公平的机会，而且我知道怎么给"。
>
> 这一段全部用 **I**，不要用 we —— `my own design` 用 our 会把责任稀释掉。

# 念的时候

**数字念成英文词。** `eighty one percent` 比 `81%` 好念，`four point nine` 不要加 percent。

**三处必须停：** 第 6 页 `It was not.` 之后、**第 10 页 `With inertia, none.` 之后**、第 10 页最后两句之间。

**三句不能改：**
- `But the problem was never in the typical run.`
- `It takes away the disaster.`
- `part of the reason the curve has no result is my own design.`

**四件不能说：**
- 不说任何做法"落后"、"简单"、"不够好"
- 不说曲线 `has no effect`，说 `cannot be resolved`
- 不说任何商业游戏内部怎么实现
- 不给 β 太大为什么更糟编解释
