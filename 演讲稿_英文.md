# Five-minute talk, English script

中文版在 `演讲稿_中文.md`，意思以那份为准，这份是**照着念的**。

**英文的标准是"简单"，不是"漂亮"。** 样例里原话是 `which is not good right ?` —— 门槛就是这个高度。
所有句子都短，都是常用词，没有从句套从句。

**每一页三部分**：页面上放什么 · 照着念的话 · 讲的时候注意什么。

---

# 1　Title

**页面上**
```
Response Curves and Action Inertia
in Utility-Based NPC Agents

Wenjie Jiang
Advisor: Navid Amini, PhD
October 2026
```

**念**

> Good afternoon. My name is Wenjie Jiang, and my advisor is Professor Navid Amini.
>
> My project is about characters in simulation games, and how they decide what to do next on their own.
>
> To be more specific: there is one approach that gives every option a score, and then picks the highest one. I measure how much two parts of that approach actually contribute.

> 第三段不能省。没有它，听众会以为你在比较所有的决策方法。

---

# 2　The Problem

**页面上**　四行，每行不超过八个词
```
Needs fall over time
Something always has to be chosen
Change too easily → nothing finishes
Never change → something gets neglected
```

**念**

> These characters have a few needs that change over time. They get hungry, they get tired. So they always have to decide which one to deal with right now.
>
> The hard part is changing their mind. If they change too easily, they never finish anything. If they never change, they hold on to one thing and let the other one get worse.
>
> So what I want to know is this. When a character behaves in a stable way, which part is actually doing the work? The two words in my title are the two parts I measure.

> 最后那个问句念完**停半秒**再进下一页。它是全场的靶子。

---

# 3　The Simulation

**页面上**　只有标题 + **Unity 截图**（俯视，看得见两个角色、冰箱、床）

**念**

> So I built a very small scene. One room. The character has two needs, hunger and energy, and both go down over time. There is a fridge, and there is a bed.
>
> I kept it small on purpose. If there are too many variables, and something happens, I cannot tell what caused it.

---

# 4　Two Agents

**页面上**　左右两栏，每栏两行
```
Threshold                    Utility

Act below a line             Score every option
Fixed order                  Pick the highest
```

**念**

> If I only build one, I cannot tell if it is good. So I built two characters. They see the world in exactly the same way. The only difference is the part that makes the decision.
>
> One uses threshold rules. When a need drops below a line, it goes and deals with it.
>
> The other one uses scoring. Every action gets a number, and the highest number wins.

> **不要说阈值规则落后或者简单。** 它回答的是另一个问题，而且后面数据会显示它在平稳环境里表现一样好。

---

# 5　Response Curves

**页面上**　只有标题 + `fig_09_curves.png`
右下角小字灰色：`(Mark, 2009)`

**念**

> So where does the score come from? From how empty the need is. That conversion is called a response curve. It is the first word in my title.
>
> It can be a straight line. Or it can be bent. I used a bent one, because urgency is not linear. Going from a little hungry to very hungry is a big change. Going from very full to a little full is almost nothing.

---

# 6　Oscillation

**页面上**　只有标题 + `fig_13_problem.png`

**念**

> With scoring in place, I thought the problem was solved. It was not.
>
> The character is sleeping. The score for eating slowly goes up. The score for sleeping slowly goes down. At some point eating wins, so it gets up and walks to the fridge. Halfway there, sleeping comes back up, so it turns around and walks back to the bed.
>
> This is what that looks like in the data. In this run, eighty one percent of its decisions threw away something it had already started.

> **这一页不能删。** 没有它，下一页的动作惯性就是凭空出现的。
>
> 「It was not.」后面停一下。

---

# 7　Action Inertia

**页面上**　公式放大，居中，下面两行小字

```
score(a) = f(need) + β · 1[a is the current action]
```
```
f   the response curve
β   the commitment bonus
```

**念**

> So I needed a second thing. Give a small bonus to whatever the character is already doing. Then another option has to be clearly better before it can push that one out. This is the second word in my title.
>
> Put together, the score for one action is this line. f is the curve. Beta is the inertia.
>
> These two control the same thing: how easily the character changes its mind. The curve decides how far apart the scores can get. The inertia decides how far apart they have to be.
>
> So I turned each one off and on. Four combinations, eight runs each.

> 教授说过八月那份 deck 没有公式。**这一页就是回应。**
>
> 念到 `f` 和 `β` 的时候用手指一下屏幕。

---

# 8　Metrics

**页面上**　三行，不要写定义
```
Interruptions
Collapse
Measurement noise
```

**念**

> Before the results, I should say what I am measuring against.
>
> For stability I count interruptions, which means how often it drops what it is doing. For failure I count collapse. If more than eighty percent of the decisions in a run are dropping something, I count that run separately, because that is a different kind of failure.
>
> And one more thing. There are two characters in the room, and they block each other. I measured how big that interference is. It is four point nine percentage points. Anything smaller than that, I do not call a finding.

> **这一页不能删。** 不先立标准，后面所有数字别人没法判断。
>
> 被问「why eighty percent」：`That line is mine. But the conclusion does not depend on it. At seventy or ninety percent, the runs with inertia still never cross it.`

---

# 9　Averages

**页面上**　BIG_NUMBER 版式
```
4.3 pp
```
下面一行小字：`the measurement noise is 4.9`

**念**

> First, with nothing removed. The four combinations sit on top of each other. The difference is smaller than the noise I just measured.
>
> So on the average, nothing shows up.

> **慢一点念。** 这一页是下一页的铺垫，听众需要先相信"什么都没有"。

---

# 10　Run by Run　　**全场重点**

**页面上**　只有标题 + `fig_03_collapse_dots.png`

**念**

> Then I stopped looking at the average, and I drew every single run.
>
> Each dot is one run. Red means that run collapsed.
>
> Look at the left side. That is the one where nothing was removed. The one where nothing showed up. Without inertia, five runs out of sixteen collapsed. With inertia, none.
>
> The average was not lying. The typical run really is the same.
>
> But the problem was never in the typical run.

> **全场最慢的一页。**
>
> `With inertia, none.` 之后停住，让它落地。
> 最后两句之间再停一次。最后一句念完不要马上翻页。

---

# 11　Reliability

**页面上**　MAIN_POINT 版式，一句话居中
```
It does not make the normal run better.
It takes away the disaster.
```

**念**

> So I changed how I describe it. At least in my setup, action inertia is more like a mechanism that removes failures, than one that improves performance.
>
> It does not make the normal run better. It takes away the disaster.
>
> If I take the fridge away for a while and then give it back, the same effect gets about ten times bigger, in the same direction.

---

# 12　Tuning

**页面上**　只有标题 + `fig_01_sweep.png`

**念**

> So is more always better? No.
>
> I tried five values, and the result is a U shape. Too small, and it cannot settle. Too large, and it gets worse again.
>
> In my setup, around zero point two to zero point three works best.

> **不要解释"为什么太大会更糟"。** 原来那个解释已经撤回了。
>
> 被问到才答：`It switches later, and it waits until the other need is lower. But why there are more interruptions, I do not have a verified explanation yet.`

---

# 13　Sensitivity

**页面上**　只有标题 + `fig_09_curves.png`（第 5 页那张再用一次）

**念**

> Now back to the first word in my title. I made the curve non-linear, and compared it against a straight line. In both cases the difference was small. I cannot tell it apart from the noise.
>
> But then I checked something. At the point where most decisions happen, the bent line and the straight line are only zero point zero one apart.
>
> To keep the comparison clean, I lined the two conditions up at the same point. And that point is exactly where most of the decisions happen. So this result may not be about the curve. It may be about how sensitive my experiment is.

> **不要说 "no effect"，要说 "cannot tell it apart from the noise"。**

---

# 14　Results

**页面上**　两行
```
Inertia removes the failures, not the average
Curve shape: cannot be resolved here
```

**念**

> Two results.
>
> Action inertia is more like a reliability mechanism. It does not improve the normal run. It removes the disaster.
>
> And the shape of the curve. In this setup, I cannot tell the difference.

---

# 15　Next Steps

**页面上**　三行
```
Sweep curvature, not just on and off
One agent per run
Add a third need
```

**念**

> But looking back, I did not treat the two mechanisms equally. For inertia I tried five values. For the curve I only had on and off. One is a sweep, the other is a yes or no question. So part of the reason the curve has no result is my own design.
>
> So, three things next. First, sweep the curvature the same way, so the curve gets the same treatment. Second, run one character at a time, to remove that four point nine of interference. Third, add a third need.

> **这一段是全场第二重要的。** 它把 null 结果从"我没做出来"变成
> "我没给它公平的机会，而且我知道怎么给"。
>
> `my own design` 这两个词要念清楚，不要含糊过去。

**念**

# 念的时候的几个提醒

**数字念成英文词，不要念符号。**
`eighty one percent` 比 `81%` 好念，也不容易卡。
`four point nine` 不要念 `four point nine percent point`。

**三处必须停：**
- 第 2 页最后那个问句之后
- 第 6 页 `It was not.` 之后
- **第 10 页 `With inertia, none.` 之后**

**三句话不能改：**
- `But the problem was never in the typical run.`（第 10 页）
- `It takes away the disaster.`（第 11 页）
- `part of the reason the curve has no result is my own design.`（第 15 页）

**四件不能说：**
- 不说任何做法"落后"、"简单"、"不够好"
- 不说曲线 "has no effect"，说 "cannot be resolved"
- 不说任何商业游戏内部怎么实现
- 不给 β 太大为什么更糟编解释
