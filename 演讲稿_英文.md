# Five-minute talk, English script

**12 页，约 4 分 45 秒。**

这份的任务是**让人听懂这个项目是什么**，不是证明结果。
结果归详细版 —— 教授要的就是 "details **with results**"，两份文件别抢同一件事。

**几乎不报数字。** 五分钟里数字听不进去，而且每一个都得防着被追问。
唯一的例外在第 9 页，那里有一对数字本身就是结论。

**人称**：做的事用 we，判断和自省用 I。

**每页三部分**：页面上放什么 · 照着念的话 · 注意什么。

Wenjie Jiang

> Good afternoon. My name is Wenjie Jiang, and my advisor is Professor Navid Amini.

> Our project is about response curves and action inertia in utility-based NPC agents.

> 念完直接翻页，不解释。

# 2　Deciding by Scoring　`34 秒`

**页面上**
- Sims 吃饭截图，占大部分版面
- 图正下方极小字：`The Sims 4, Electronic Arts`
- 右下角小字灰色：`(Mark, 2009)`

**念**

> This is The Sims. The characters here look after themselves. They get hungry, and they go and eat.
>
> They have more than one need at the same time, so they always have to choose. Getting that choice right is harder than it looks.
>
> We wanted to know how that kind of behaviour is built. One approach is scoring. A character has several things it could do, and it gives each one a score. It does the one with the highest score.
>
> Response curves and action inertia are two parts of how that score is worked out. Those two are what we measure.

> 第二段是钩子，不展开。第 6 页才揭晓。
>
> 被问「Why cite Mark here?」：
> `Because scoring is an existing approach, and that is where it is set out.`

# 3　The Setup　`22 秒`

**页面上**　只有标题 + **Unity 截图**（俯视，看得见两个角色、冰箱、床）

**念**

> So we built a very small version of that. One room. The character has two needs, hunger and energy, and both go down over time. There is a fridge, and there is a bed.
>
> We kept it small on purpose. If there are too many variables, and something happens, we cannot tell what caused it.

# 4　Two Agents　`22 秒`

**页面上**　两栏，用场景里那两个圆圈的实际颜色当标记
```
  ● Threshold              ● Utility

  Act below a line         Score every option
  Fixed order              Pick the highest
```

**念**

> We built two characters. They see the world in exactly the same way. The only difference is the part that makes the decision.
>
> One uses threshold rules. When a need drops below a line, it goes and deals with it.
>
> The other one uses scoring. Every action gets a number, and the highest number wins.

> **不要说阈值规则落后或者简单。** 它回答的是另一个问题。

---

# 5　Response Curves　`22 秒`

**页面上**　只有标题 + `slide_curves.png`
右下角小字灰色：`(Mark, 2009)`

> **这一页用图，不要用表。** 表格丢掉了坐标的含义 ——
> 光看 `need 0.2` 不知道那是饿还是饱。

**念**

> So where does that number come from? From how empty the need is. That conversion is called a response curve. It is the first word in our title.
>
> It can be a straight line. Or it can be bent. We used a bent one, because urgency is not linear. Going from a little hungry to very hungry is a big change. Going from very full to a little full is almost nothing.

---

# 6　Oscillation　`30 秒`　**不能删**

**页面上**　只有标题 + `slide_problem.png`

**念**

> With scoring in place, I thought the problem was solved. It was not.
>
> The character is sleeping. The score for eating slowly goes up. The score for sleeping slowly goes down. At some point eating wins, so it gets up and walks to the fridge. Halfway there, sleeping comes back up, so it turns around and walks back to the bed.
>
> That is what I mean by oscillation. In this run, eight out of every ten decisions dropped something it had not finished.

> **这就是第 2 页说的 "harder than it looks"。**
> 没有这一页，下一页的动作惯性就是凭空出现的。
>
> `It was not.` 之后停一下。

---

# 7　Action Inertia　`34 秒`

**页面上**　公式居中放大，下面两行小字
```
score(a) = f(need) + β · 1[a = current action]
```
```
f   response curve
β   commitment bonus
```

> 普通文本框粘上面那行字就行，**里面没有反斜杠**。
> f 设灰色，β 设橙色 —— 旧的压灰，新的高亮。

**念**

> So we needed a second thing. Give a small bonus to whatever the character is already doing. Then another option has to be clearly better before it can push that one out. This is the second word in our title.
>
> Put together, the score for one action is this line. f is the curve. Beta is the inertia.
>
> These two control the same thing: how easily the character changes its mind. The curve decides how far apart the scores can get. The inertia decides how far apart they have to be.

> 教授说过八月那份 deck 没有公式。**这一页就是回应。**
> 念到 f 和 β 时用手指一下屏幕。
>
> 被问「Is action inertia a standard term?」：
> `The idea of committing to what you are already doing goes back to work on intentions, Bratman and others. The name and the exact form in my implementation are my own choice.`

---

# 8　Metrics　`28 秒`　**不能删**

**页面上**　三行，不要写定义
```
Interruptions
Collapse
Measurement noise
```

**念**

> Before I say what we found, I should say what we measure against.
>
> For stability we count interruptions, which means how often it drops what it is doing. For failure we count collapse, which is a run where it drops almost everything it starts. That is a different kind of failure, so we count it separately.
>
> And one more thing. There are two characters in the room, and they block each other. We measured how big that interference is, and anything smaller than that, we do not call a finding.

> **不能删。** 不先立标准，后面那一页别人没法判断。
>
> 被问具体数字：`Four point nine percentage points.`
> 被问「How do you define collapse?」：`More than eighty percent of the decisions in a run.
> That line is mine, but the conclusion does not depend on it — at seventy or ninety percent it holds too.`

---

# 9　What We Found　`40 秒`　**全场重点**

**页面上**　一张表

| | nothing removed | resource removed |
|---|---|---|
| **without inertia** | **5 of 16** | **7 of 16** |
| **with inertia** | **0 of 16** | **0 of 16** |

**念**

> We ran this a hundred and four times. Each combination, eight times, with different starting conditions. And then again with a resource taken away in the middle.
>
> Here is the one result I want to show today.
>
> Without inertia, some runs collapse completely, even with nothing taken away. With inertia, that never happened. Not once.
>
> The average run is about the same either way. It does not make the normal run better. It takes away the disaster.

> **全场最慢的一页。**
> `Not once.` 之后停住。最后两句之间再停一次。
>
> 表格里那四个数不用念出来，**让它们在屏幕上自己说**。
> 要是觉得表格太具体，整页换成一句大字也行：
> `Without inertia, some runs collapse. With inertia, none did.`

---

# 10　Next Steps　`30 秒`

**页面上**　三行
```
Sweep the curve, not just on and off
One character per run
Add a third need
```

**念**

> Looking back, I did not treat the two mechanisms equally. For inertia I tried five different strengths. For the curve I only had on and off. So part of the reason the curve has no clear result is my own design.
>
> So, three things next. Sweep the curve the same way, so it gets the same treatment. Run one character at a time, so they stop interfering with each other. And add a third need.

> **这一段全部用 I，不要用 we** —— `my own design` 用 our 会把责任稀释掉。
>
> 它把 null 结果从"我没做出来"变成"我没给它公平的机会，而且我知道怎么给"。

# 念的时候

**两处必须停：** 第 6 页 `It was not.` 之后、**第 9 页 `Not once.` 之后**。

**三句不能改：**
- `That is what I mean by oscillation.`
- `It takes away the disaster.`
- `part of the reason the curve has no clear result is my own design.`

**四件不能说：**
- 不说任何做法"落后"、"简单"、"不够好"
- 不说曲线 `has no effect`，说 `no clear result`
- 不说任何商业游戏内部怎么实现
- 不给"惯性太大为什么更糟"编解释（那是详细版的事，而且目前没有已证实的解释）
